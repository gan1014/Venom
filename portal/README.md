# LEGO LEVIATHON — Build Beyond Limits

Free AI Hackathon 2026 portal. The original 3D scroll hero is preserved under `public/` (`js/app.js`, `css/style.css`, `assets/frames`). It is not rewritten.

```
npm run dev
```

Open the preview on port 3000.

## Flow
Home (3D hero) → Event → Register → Unique Team/Symbiote IDs → QR pass → Dashboard → Admin check-in

## Admin
- Email: `admin@leviathan.local`
- Password: `LEVIATHAN-ADMIN-2026`

Change via `.env.local`.

## Data
Local JSON store: `data/db.json`  
Production schema: `supabase/schema.sql`
